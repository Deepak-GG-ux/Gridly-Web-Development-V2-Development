Internship overview

The Gridly Web Development Internship is a project-based placement rather than a course. The intern takes a single website from an empty repository to a deployed production site, and is expected to justify technical decisions rather than only implement them.

The project used for this placement is the Gridly website itself: a multi-page company site with a design system, data-driven content, an accessible component library, a validated contact form and a certificate verification system. Every feature on this site was part of the internship scope.

Work was carried out remotely, tracked in Git, and deployed continuously from GitHub to Netlify.
